# Tasks

以下为本变更的实施与验收清单，以勾选状态记录真实进度。`[后端]` 由 Codex 实现 API、数据库、契约及后端测试；`[前端]` 由协调 Agent 通过 Computer Use 操作 Antigravity 完成；用户本次已授权Gemini从既有草图重新视觉设计并实现，最终视觉仍需验收；`[联调]` 由协调 Agent 验证，问题按文件归属回到对应实现方。共享契约由后端维护，禁止同时修改同一文件。

2026-11-11：用户授权 Gemini 将现有 v3 图作为业务草图重新视觉设计，未接受旧图视觉，也未确认最终方案；主代理已实际投递至Antigravity的Gemini3.8FlashHigh，当前实现中。本次文档同步不改变任何任务勾选，前端完成以实际验收为准。

依据：[设计](design.md)、[数据库](docs/database-design.md)、[契约](docs/api-contract.md)及十项 `specs/*/spec.md`。各组随实现交付自己的测试和说明，末组只做跨模块验收。

- [x] 1.1 [后端] 建立 TypeScript 严格模式的 API、contracts、database 工作区并锁定核查后的依赖；验证安装和实际新增的类型检查、测试、构建命令可运行，不编写 web 实现。
- [x] 1.2 [后端] 将规划 OpenAPI 落实为共享输入/输出校验和类型，明确角色响应投影、十进制字符串及整数上限；验证全部 schema、示例、额外字段拒绝及基线语义差异，更新契约说明。
- [x] 1.3 [后端] 建立真实 PostgreSQL 测试数据库与隔离数据夹具，新增迁移执行方式；验证测试可重建空库，事务/锁测试不以 SQLite 或内存模拟替代。
- [x] 1.4 [后端] 实现分/高精度单价、换算、比例优惠、尾差和原金额回退工具；用 10 元/24 瓶、逐瓶销售、全部退回及多行减免的性质测试验证数量金额守恒并记录精度约定。

- [x] 2.2 [后端] 实现管理员账号维护和首次管理员初始化方式；验证最后管理员不能被停用/降级，初始化过程不将真实凭据写进仓库或日志。
- [x] 2.3 [后端] 建立业务操作、幂等注册/结果、审计及统一错误响应；验证相同键同正文重放、不同正文冲突、租约恢复、失败重放及权限先于缓存，并补充运行说明。

## 3. 商品、客户、单位与价格

- [x] 3.2 [后端] 实现后端助记码持久化、改名同步、人工校正及检索；验证 `500ml酱油 → 500mljy`、大小写、数字英文、同码多商品、前导零条码和校正后改名，不使用只覆盖样例的替换表。
- [x] 3.3 [后端] 实现客户多地址与订单配送快照所需查询；验证默认地址、停用地址、地址所属客户和资料改动不覆盖已生成快照。
- [x] 3.4 [后端] 实现历史有效成交价 → 专属价 → 默认价回填；验证同单位、全退/作废排除、旧单修改时间不抢最近记录、同单多行稳定选择及折后单价来源。

## 4. 入库、批次与盘点

- [x] 4.1 [后端] 建立入库、批次、商品仓库汇总、库存流水及盘点迁移；验证源行防重、非负及安全整数约束，汇总可由批次/流水核对重建。
- [x] 4.2 [后端] 实现采购/期初入库、实际成本及时间补录；验证每次来源独立、同时间稳定顺序、记录实际与登记时间、补录不改历史销售成本，并更新入库 API 文档。
- [x] 4.3 [后端] 实现统一库存锁顺序和自动/手动分配；验证自动跨批、同商品重复行联合校验、手选不足须补选、禁止自动跨仓与并发不超卖。
- [x] 4.4 [后端] 实现盘点快照、实盘、盘亏指定批次及盘盈新批成本；验证库存变化导致旧快照拒绝、损益独立、不覆盖旧销售毛利及重复确认防重。

## 5. 客户账户底座

- [x] 5.1 [后端] 建立客户账户、商业分录、期初往来、现金及核销数据模型；验证账户合计与分录一致、正负余额及资料外键，期初不算新销售或实收。
- [x] 5.2 [后端] 实现供订单/退货调用的同事务商业应收调整与重分类；验证跨月更换客户逐笔保留原业务日、实际现金不迁移，并记录客户账户锁顺序和来源说明。

## 6. 订单确认与更正

- [x] 6.1 [后端] 实现草稿、预估报价、快照、内容版本及配送元数据；验证草稿不占库存、不生成应收，报价不产生虚构已持久化标识，配送标记不扣库。
- [x] 6.2 [后端] 实现订单确认的一次事务：跨仓分配、金额优惠、成本、毛利与应收；验证缺货任一行则全单失败、重试不重复、同商品不同仓拆行保留。
- [x] 6.3 [后端] 实现按行命令的已确认改单；验证改价不动库存、不变行保留原成本、增量/改仓仅调整相关部分、失败原样、版本冲突不覆盖。
- [x] 6.4 [后端] 实现优惠与抹零分摊及客户变更账户摘要；验证负毛利、优惠超额拒绝、尾差、解除无效核销及现金事实不改，补齐接口示例。
- [x] 6.5 [后端] 实现未配送作废及已有更正/退货来源合并；验证仅恢复未回补量、关闭待返库、销售/信用/损失不双重冲销、现金保留，已配送作废拒绝但仍可改单。
- [x] 6.6 [后端] 实现管理员/员工独立订单列表、详情、历史 DTO 与来源查询；验证员工响应、嵌套和错误中完全没有成本毛利字段，不能仅用 union 校验代替角色校验。

- [x] 7.2 [后端] 实现分次实际返库及待返库/明确损失追溯；验证原仓原批原成本、重试不双加、未退款/已退款均不替代返库，并核对损失冲正来源。
- [x] 7.3 [后端] 实现退货后改单的只读历史段与可编辑余量；验证 1 件 12 瓶退 3 瓶后改余量/价格、不得删除已退来源、不得低于已退量、不得重复回补，补充契约和审计样例。
