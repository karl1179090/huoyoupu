# Spec Delta

## Purpose

为管理员提供自然语言经营查询入口，将问题落实为可审查的统计条件并返回可复核的指标和来源，复用普通报表的业务口径，避免模型自由编造数据或执行业务写入。

## ADDED Requirements

### Requirement: 受控只读查询
系统 MUST 仅允许管理员使用 AI 查询；模型只可选择获准的指标、维度、过滤条件与期间，后端独立验证参数并计算结果，不能执行任意 SQL 或订单、库存、价格、资金写入。

#### Scenario: 自然语言要求改库存
- **WHEN** 用户要求 AI 为某商品增加库存或修改订单
- **THEN** 系统不执行写操作，明确该入口只支持已定义统计

#### Scenario: 员工直接调用 AI
- **WHEN** 员工提交自然语言查询
- **THEN** 后端先拒绝，不访问模型或返回统计数据

### Requirement: 与固定报表相同的口径
系统 MUST 通过同一统计能力产生固定报表和 AI 数值，应用已定义的同期、跨期更正、基础单位、下单量及退货规则；关键歧义需要澄清，采用默认值时必须展示实际条件。

#### Scenario: 客户商品下降问题
- **WHEN** 管理员问哪些客户本月某商品下单量比上月少
- **THEN** 默认比较上月同期的有效下单量，包含本期零购买，并单列退货量与净销量

#### Scenario: 客户名称不唯一
- **WHEN** 问题中的客户简称匹配多个客户且影响结果
- **THEN** 返回候选和澄清问题，不能静默选一个客户

### Requirement: 可核对的回答
系统 MUST 在回答中提供规范化查询条件、两个比较期间、单位、截止点、结构化数值和明细来源；模型叙述不得替代或修改数据库产生的精确数值。

#### Scenario: 普通报表复核
- **WHEN** 管理员以 AI 回答附带的结果标识打开普通报表
- **THEN** 能复现同一结果及当时引用的订单版本

### Requirement: 异常与能力范围
系统 MUST 在模型不可用、输出不合法、查询超限或没有匹配数据时给出准确状态；不能编造成功统计。已获得的合法查询条件可用于普通报表，不得因模型失败损坏业务数据。

#### Scenario: 模型超时
- **WHEN** 模型服务未在限时内响应
- **THEN** 返回可重试或普通报表替代提示，不生成虚构结论，不执行写操作

### Requirement: 模型数据和凭证边界
系统 MUST 只向模型提供完成授权统计所需的数据，不将服务端凭证、密码、会话秘密或无关客户联系方式放入提示或响应；模型输出必须再次校验，不作为权限来源。

#### Scenario: 非法工具参数
- **WHEN** 模型生成未获准字段、额外 SQL 或超范围过滤条件
- **THEN** 后端拒绝该调用或要求澄清，不按模型指令扩大权限
