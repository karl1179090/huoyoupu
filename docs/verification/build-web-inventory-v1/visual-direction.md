# 视觉参考准备（未生图、未确认）

已读取 imagegen 与 ui-ux-pro-max 技能。此文件仅给下一步生图的覆盖依据，不是用户已确认的设计，也不包含前端实现。

建议采用浅色、紧凑但可读的业务工作台：石板灰导航、白色内容区、深绿主操作，红色仅表示危险或异常。中文使用清晰无衬线字，金额用等宽数字并右对齐；边框和留白组织层级，少阴影，不使用装饰渐变。桌面以表格、筛选和固定合计区支持连续开单；手机以纵向明细卡、分步编辑和固定主操作支持触控，保留同一权限和能力。

技能检索说明：design-system 查询返回 Flat Design 和工业灰/库存绿，与业务场景相符；同时返回的营销落地页 Feature-Rich Showcase 布局不适用，因此未采纳。按要求收窄检索 `operations dashboard flat --domain style` 后，Data-Dense Dashboard 与 Flat Design 适配此后台；使用其布局原则，不采用不属于需求的导出或图表交互建议。

| --- | --- | --- | --- |
